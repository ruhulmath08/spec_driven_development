# Spec driven development

Spec-Driven Development (SDD)

## What is specs.md?

specs.md is a file that contains the specs for the project. It is used to describe the requirements for the project and to guide the development of the software.

## How to use specs.md?

1. Write the specs for the project in the specs.md file
2. Use the specs to guide the development of the software
3. When you are done, run the tests to ensure that the software meets the requirements

## How to run the tests?

1. Run the tests by running the command `npm run test`
2. The tests will be run and the results will be displayed in the console
3. If the tests fail, you will need to fix the software to meet the requirements
4. If the tests pass, you can be confident that the software meets the requirements
